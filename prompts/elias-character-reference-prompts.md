# I-RULE01: CREATIVE FIRE — Elias Character Reference Prompt

A standalone prompt for generating a clear, consistent look at Elias himself — full character visibility, not a silhouette. Use this to lock his design before generating any more scene pages, and re-use this same description any time he needs to appear un-silhouetted elsewhere.

---

### CHARACTER REFERENCE — Elias, Full Turnaround Sheet

Five separate views for a complete character reference. Generate each one individually. All five should match exactly — same suit, same proportions, same bronze seam pattern — so treat this as one character design locked across five angles, not five different interpretations.

---

Matte obsidian-black technical suit, form-fitting but practical, with fine bronze seam-lines running down the arms, chest, and legs like dormant circuitry, currently dim and unlit. Plain light-gray studio background for clear silhouette reading, soft even lighting from the front, no shadows obscuring the design. Badge: "THE CARRIER." Small bold text at the bottom: "FRONT VIEW." ### Optional — Aligned State (Repeat Any View Above)
For any of the five views above, you can generate a matching "aligned" variant: identical pose and framing, but with the bronze seam-lines fully glowing amber-bright instead of dim. Keep everything else in the prompt the same — only the seam-glow description changes.

---

## Notes
- Generate all five views in the same session if your tool supports it, so the suit design, proportions, and lighting stay consistent across the set — otherwise generate Front first and reference it when prompting the other four.
- Switched to a **plain studio background** for this turnaround sheet instead of the atmospheric world backdrop — a clean background makes it much easier to check proportions and design consistency across all five angles, and you can always composite him into a scene backdrop later.
- These are simple, low-risk prompts (no height, no isolation, no ritual imagery) — they should generate cleanly without the moderation issues some of the stage pages hit.
