# Glossary

| Term | Meaning |
|---|---|
| **Igara** | The Realm of Unlit Fire: the broken floating world |
| **Elias** | The 21-year-old carrier and player character |
| **The Carrier** | Role title for Elias; badge on character art |
| **Six Lines / Sky Ladder / Hexagram of Heaven** | Six horizontal fire bars in the sky; one ignites per stage, bottom to top |
| **Fire Eye** | The world-level watching system that opens as lines ignite |
| **Cinder** | The guidance fire-fragment that replaces the HUD |
| **Sacred Arc** | The flowing fire presence on Elias's bow arm that turns arrows into fire arrows when aligned |
| **Fire Dragon** | The guardian and recurring trial; mirror of the player's state |
| **The Throne** | The final seat; activation and recognition rather than victory |
| **Entropy / Freshness / Beauty** | The three world states of the Creative Energy Cycle |
| **Creative Energy Cycle** | The hidden state machine that evaluates behaviour |
| **ForcingIndex** | The single 0-1 internal meter of how hard the player is forcing |
| **Stillness** | Continuous non-movement, the game's central verb |
| **Rock gate** | ENV-04's exit: the two tallest natural rock spires lean together. A short stone bridge leads out between them |
| **Brittle slab** | ENV-12. A rock slab that cracks about 2 seconds after the player steps on it. Keep moving or dash |
| **Ember Leech** | Small armoured crawler (about 40 cm). Drains platform stability. Calm makes fewer of them |
| **Bat-bird** | Large dark bird with leather wings. Islands 1 and 2 only |
| **Calm Pocket** | A volume where stillness registers faster; storm-reset spots |
| **Still Window** | 2 s of stillness that clears a storm |
| **Ignition column** | The receptacle where a line is ignited by a stillness hold |
| **Lantern anchor (XL)** | Extra-large lanterns that act as the world's progress map |
| **Heat current** | A readable rising air column used for flight in Stage 5 |
| **Ring of Fire** | The world ignition at the ending |
| **Hexagram 1 (Ch'ien, The Creative)** | The I Ching hexagram of six unbroken lines that inspires the game |
| **Open frame** | The window in which an enemy can be hit or shattered |
| **Golden path** | The first-time average run used for timing |
| **Look lock** | The art rules that keep every asset matching the key art |
| **Key art** | The approved rendered images that set the look |
