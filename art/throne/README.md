## Approved sheet (v1)
`art/assets/THR-01/sheet.jpg` is the first approved multi-angle sheet and the current look reference for the Throne (dark volcanic stone, bronze ribs, glowing fissures, staircase with braziers, mid-gray backdrop).

**Revisions for the final:**
- **Six fissures**: the sheet shows five bars. Canon is six.
- **Two dragon ribs**: the sheet shows many tusk-like ribs. Design calls for two colossal ribs, one on each side, arching inward.
- **Height**: it should read taller against the staircase and tiny figure (about 40 m).
