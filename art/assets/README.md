# Asset images

One folder per asset ID. Drop images using the names in [docs/15-asset-tracker.md](../../docs/15-asset-tracker.md).


## Thumbnails

The website shows `thumbs/<name>.jpg` when it exists (about 1100 px, fast to load) and links the full image for download. If you add only the full image, the site still works, it just loads the full file.
