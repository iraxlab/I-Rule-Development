# 33 Rules applied to I-RULE01

**APPLIED 15 Nov 2026.** Every rule marked Fits or Check in [doc 32](32-rules-of-successful-games.md) is now a spec below, unless it breaks locked canon. Numbers are targets. Tune them in playtests.

## 1. Feel (GF)
Full spec: [Core systems, section 9](06-core-systems.md#9-feel-rules-applied).

| Rule | What we do |
|---|---|
| GF-1, GF-2 | One action per input. A fixed priority table settles two buttons pressed together. |
| GF-3 | Every state change has a visible or audible cue. No hidden state changes. |
| GF-5, GF-14 | The empty-room test: movement must be fun on grey boxes, before any art. |
| GF-7, GF-8 | Every input shows a result within 100 ms. The stillness hold keeps its locked times. |
| GF-9 | 60 fps target on PC. Never below 30. Stillness and bridge logic run on a fixed tick. |
| GF-13 | At least 3 variants of every repeated sound and animation. |
| GF-15 | Falls and bridge breaks have at least 3 variants each, and look good. |
| GF-16, GF-17, GF-18 | Motion follows arcs. Look, sound and physics say one thing. The world stays mythic and iconic. |
| GF-19 | A no-clipping pass on every island before sign-off. |
| GF-21, GF-22 | Weight cues for big things: Dragon, bridge chains, the Throne. |
| GF-25 | A feel sheet for each mechanic, logged in playtests. |

## 5. Held back
These rules fit most games but would break locked canon, so they are not applied. Each has a replacement.

| Rule | Why held | What we do instead |
|---|---|---|
| Leaderboards, high scores, stars (PY-R2 to PY-R4, PY-R14, PY-R15) | Canon: no ranks or scores | A silent Still Path record |
| Pre and post event screens (PY-8, PY-9) | Canon: no HUD, no text | The world frames each stage |
| Health bar (UN-4) | Canon: no HUD | Suit seams and sound |
| Difficulty select (UN-11) | Hold times are locked and fairness is built in | Calm pockets, Cinder catch, quiet help |
| Spawn pressure over time (UN-8) | It fights the stillness idea | None |
| Random start positions (UN-10) | Islands are hand made | None |
| Challenges, social features (PY-R16, PY-R18) | Single player, no online | None |
| Seasons, real time, appointments (PY-R5, R11, R12) | Premium, not a service | None |

## 6. Not decided yet
1. **Steam achievements.** One for each Line and each Still Secret, named by function. No in-game pop-ups. Which ones is not decided.
2. **How the Still Path record shows.** Stored per stage (time and clean builds). Shown only as a tint on the ember at stage end. Not decided.
3. **A Stillness Assist setting.** It would widen the movement tolerance and never the hold time. It needs owner approval because hold times are locked.
