# Contributing

Thanks for helping. This repo is the source of truth, so changes should be small, clear and traceable.

## Before you change anything
1. Read [Canon and open decisions](docs/13-canon-and-open-decisions.md). **Locked canon needs owner approval.**
2. Check the [glossary](GLOSSARY.md) for the right term.
3. Search for the topic: one fact lives in **one** document. Update that one, do not copy it.

## Pull requests
- One topic per pull request.
- Say what changed and why. If it touches canon, say so in the title.
- Keep numbers consistent with the stage documents (hold times, timings).
- Link, do not duplicate.

## Style
- Plain, direct sentences. Short tables for comparisons.
- Use the key-art names for stages.
- No religious framing, no specific-person enemies, Unreal Engine terms.
- Name every image with what it is (`stage-3-the-toil.jpg`, not `image-7.jpg`).

## Adding art
- Put it in the right `art/` folder, optimised (JPEG, longest edge about 1920 px).
- Add it to [`art/README.md`](art/README.md) with its name.
- Add the prompt that produced it to [`prompts/`](prompts/).

## Issues
Use the templates: **Question** (something is missing or unclear), **Canon conflict**, **Change request**.
